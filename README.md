# Демоверсия сайта Евстратова

Статическая копия для согласования дизайна. Форма составляет текст в браузере для ручной отправки. Заявки не отправляются на сервер. Тестовая статистика хранится только в браузере после согласия. Внешние счётчики не подключены. Контакты опубликованы на официальном сайте компании.

В репозиторий включены только файлы сайта. Секреты, журналы, базы данных и история рабочего проекта не включены. GitHub Pages обрабатывает технические запросы посетителей согласно правилам GitHub.


## Client version, 16 October 2026

Six public sections in Russian and English: home, delivery, company, founder, cases and an illustrative estimate. AI-branded transport visuals were generated in the Gemini app using the Nano Banana request and are explicitly identified as concepts, not proof of fleet ownership.

The estimate uses fictional browser-local coefficients. It has no connected AI model, live rate feed, API key or server-side lead collection. Special cargo is referred to an expert. English reference privacy documents are provided. Published business figures are attributed to the official company website and are not independently audited.


## Photo-based imagery, revision 9

Transport and workspace visuals now use real licensed source photographs with AI-assisted paint/branding edits based on the client Boeing 747-8F livery passport. Sources, authors, changes and licence links are in credits.html, en/credits.html and assets/media/photo-sources.json. CC BY-SA photographic adaptations retain that licence; trademark rights are separate. Original source photographs and the private project passport are not bundled in this repository.
